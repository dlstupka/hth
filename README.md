# Golden Set Winner Summary overlay

Apply this overlay at the directory containing the `hth/` repository folder.

It adds:

- Top 5 parameter-set leaderboard
- Golden Set Winner Summary table using **Golden Set Page**
- Signed `Δ IoU` without an arrow column
- Parameter Set column on every winner-page row
- Explicit Problem Pages counts and details
- Canonical `reports/winner-pages.json`

The heartbeat output is unchanged.
