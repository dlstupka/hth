# Orli Page-Mask Detector

`orli_page_mask` uses the managed Orli historical-document base model to produce ordered segmentation evidence and converts that fixed learned evidence into an HTH page mask. The neural model is not trained or modified by calibration. HTH calibration parameters operate only on the deterministic evidence returned by the fixed model.

The expensive neural inference stage is therefore parameter-invariant. For a given model, resized Golden Set page, and inference contract, HTH can safely reuse the same Orli evidence for every calibration parameter set and every execution shape. The regression driver still creates a run-local shared-evidence manifest for worker fan-out, but that manifest may now be hydrated from the persistent results-repository evidence store instead of rerunning Orli.

## Learned-geometry envelope refinement

The Orli historical base model often emits baseline geometry without region or line polygons. Earlier page-mask conversion rasterized those baselines and selected an external connected contour. On dense two-page spreads that can collapse hundreds of valid learned baselines into one connected text block or one column, even though the complete Orli evidence spans the document.

The detector now derives a second, parameter-free **learned-geometry consensus envelope** directly from the retained region, line, and baseline coordinates. Extremely short baseline fragments are rejected conservatively, the remaining learned points are combined into a convex outer support, and a minimum-area quadrilateral is fit to that global extent. HTH compares this learned-geometry envelope with the morphology-derived contour envelope using **directional extent arbitration** before applying the existing calibrated page padding and minimum-area gate. A morphology contour is no longer allowed to win merely because it has greater total area: if the learned geometry adds a material horizontal or vertical document span while retaining substantial support in the orthogonal axis, the learned quadrilateral is preserved.

Verbose calibration showed that this alone was insufficient on several HTH-0001 pages: Orli baselines accurately described a broad text frame but both the raster contour and direct learned envelope terminated around the text rather than the physical paper edge. The detector therefore derives a third, parameter-free **learned document frame** when at least four substantial baselines cover a majority of the document axis. Baseline directions are combined axially to estimate the document orientation, the learned text support is projected into that coordinate system, and the leading/trailing text margins along the document axis are used to infer a conservative orthogonal paper margin. The frame extrapolates only the missing cross-axis extent; localized text blocks are rejected instead of being promoted to page-sized proposals. Existing `page_padding_fraction` remains the calibrated final expansion after arbitration.

Arbitration now considers the morphology contour, direct learned envelope, and inferred document frame. A learned document frame wins only when it restores a material document-axis extent while retaining substantial orthogonal support. The historic area comparison remains a fallback for the two observed envelopes when no inferred frame qualifies. Verbose diagnostics record the dominant baseline angle, main-axis coverage, row spacing, inferred cross-axis margin, all candidate bounds/areas, span ratios, the arbitration reason, and the selected source.

A further parameter-free **directional page completion** step handles the complementary failure mode visible in HTH-0001 verbose evidence: an Orli proposal can accurately anchor two or more physical page sides (for example top+right or top+left) while terminating hundreds of pixels early on the opposite sides. After envelope arbitration, HTH projects the selected quadrilateral and source image into the proposal's own orthogonal basis. If the proposal is anchored near at least two image sides and an axis covers less than 72% of the available span while the opposite margin is materially missing, only that missing side is completed by mirroring the trusted image-edge margin. Broad page proposals are left unchanged, and unanchored localized text blocks are never promoted. Existing `page_padding_fraction` remains the final calibrated expansion. Verbose diagnostics expose anchor count, per-axis spans/margins, changed sides, completed bounds, and the completion reason.

This changes only the deterministic interpretation of existing Orli evidence. It does not retrain the model, invalidate persisted evidence, add calibration parameters, or expand the live parameter grid.

See [Orli learned-evidence persistence](orli-evidence-persistence.md) for the persistent identity, evidence index, repository layout, and invalidation rules.


## Parameter liveness

The completed 10,000-set HTH-0001 characterization classified `close_kernel_fraction` and `fill_holes` as empirical zombies for the current Golden Set/grid. Normal `exhaustive` calibration pins them at the detector baseline values `0.006` and `1`, respectively, and searches the four live dimensions. The same baseline-pin rule applies to every parameter excluded by a contracted effect-size search, keeping complete Parameter Set IDs invariant across builds. The explicit `exhaustive-with-zombies` strategy restores their retained historical domains and reconstructs the original 10,000-set space for deliberate revalidation. See [Detector Parameter Liveness Audit](parameter-liveness-audit.md).

### Corner-anchored two-axis completion

Directional completion also recognizes the stricter case where a localized Orli proposal is physically anchored to two adjacent source-image sides while both opposite page dimensions are materially absent. In that case the trusted corner margins are mirrored to reconstruct both missing sides together. Physical-corner qualification is evaluated independently of the proposal's rotated-basis anchor count: a rotated fragment may project to only one trusted basis side even while its axis-aligned bounds clearly touch a real source-image corner. This closes the HTH-0001 page-10 failure where the physical-corner fallback existed but an earlier rotated-basis rejection made it unreachable. The fallback remains intentionally narrower than generic envelope growth: unanchored localized text blocks remain ineligible, and broad page proposals are left unchanged. Verbose envelope diagnostics identify `corner-anchored-two-axis-completion`, the trusted corner, physical margins, synthesized sides, and completed bounds.

### Image-supported missing-boundary recovery

The remaining HTH-0001 page-10 failure is different from the broad-frame and physical-corner cases above: Orli supplies a coherent localized fragment that identifies the document, but the learned proposal does not actually touch enough source-image sides to justify geometric extrapolation by itself. HTH therefore adds a final, parameter-free fallback that uses the learned proposal only as the seed and requires the source image to independently prove any missing physical page boundary before the proposal is enlarged.

The fallback runs only when directional completion did not already succeed, the seed is localized and near axis-aligned, at least one seed side is reasonably close to a source-image side, and one or more opposite sides are materially absent. Cached Sobel boundary profiles are built once per source image; robust outer-image peaks must exceed a median/MAD evidence threshold before a missing side can be accepted. A two-axis fragment requires both missing sides to be independently supported, preventing a strong text rule or local contrast edge from inflating an arbitrary text block into a page. Existing broad-page and directional-completion results are therefore preserved unchanged.

Verbose envelope diagnostics record seed bounds and area/span fractions, trusted seed margins, every attempted boundary search with robust score, recovered sides, completed bounds, and the `image-supported-boundary-recovery` decision. The neural model, persisted learned evidence, calibration grid, and parameter identities are unchanged; this stage changes only deterministic interpretation of the source image plus already-cached Orli evidence.

## Post-recovery parameter-space recharacterization

Image-supported missing-boundary recovery materially changed Orli's deterministic response surface on HTH-0001, raising the detector baseline and eliminating the former page-10 failure. The previous winning calibration also landed on two live-grid boundaries: minimum page area at the low edge and page padding at the high edge. The live exhaustive grid is therefore expanded conservatively to include minimum-page-area fractions `0.04` and `0.06` and page-padding fractions `0.14` and `0.16`. The resulting live space contains 1,680 exact parameter sets (16,800 under `exhaustive-with-zombies`).

This is a calibration-space refinement only. The Orli model, persisted learned evidence, parameter semantics, zombie/equivalence enrollment, and exact Parameter Set identity contract are unchanged. A fresh exhaustive regression should be treated as the authoritative characterization of the post-recovery detector.
